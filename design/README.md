# 跟班 Sidekick 首轮品牌与交互设计

这是可评审的设计原型，布局已确认采用“今日事项主列表＋右侧班班简报”，待确认收件箱独立进入。这些原型不代表生产能力；实际实现与未验项见[实施计划](../docs/product/05-第一阶段实施计划.md)。当前先验收 Web 完整业务，薄壳后置；现有品牌与布局保留，队列/错误/系统能力缺失状态按新目标补充。

## 预览

在仓库根目录运行窄范围只读预览服务（Node 标准库，无额外依赖；`PORT` 可覆盖端口）：

```sh
node design/serve.mjs
```

- 设计索引：`http://127.0.0.1:4173/design/`
- 品牌板：`http://127.0.0.1:4173/design/brand/`
- 交互原型：`http://127.0.0.1:4173/design/prototype/`
- 任务队列交互方案：`http://127.0.0.1:4173/design/web-task-flow/`

服务只暴露 `/design/`、`/src/assets/` 与 `/src/styles/`，其余路径返回 404；浏览器访问 `/` 会跳转到 `/design/`。原型引用的是 `src/` 中的生产品牌资产与设计令牌。

交互原型使用虚构演示资料，不调用模型、飞书、MCP、Bash或本机文件系统；更改仅留在当前页面，刷新可复位。请勿输入真实密钥或业务资料。

## 任务队列交互方案（W0）

`web-task-flow/` 是 W0 的浏览器任务面板演示：默认 3 并发与执行槽占用、满槽持久排队与排队位置、提交幂等、取消排队与取消运行中（`cancelling` 未终态）、失败分类与重试边界、`needs_review` 逐项核对、备份恢复暂停与隔离、凭据不可用、以及原生不可用能力的壳适配点。交互契约见[任务交互设计](../docs/engineering/web-task-interaction.md)。

演示只用合成数据：不连接模型、飞书、MCP、Bash、SQLite 或本机文件系统，刷新复位；不用合成 IPC 代签真实服务。状态切换与文案对应该契约，接口字段名、错误码取值以契约冻结为准。

## 交付边界

品牌图形使用原生SVG，字体Space Grotesk随附OFL许可；中文使用系统苹方与无衬线回退。原型用于验证信息层级和操作动线，不是Tauri/Vue生产工程，也不证明系统通知、拖拽穿透、数据持久化或真实接入能力。

参考基线：[产品定义](../docs/product/01-产品定义.md)、[用户流程](../docs/product/02-用户流程.md)。

## 原型走查

可体验：文本示例→编辑候选→批量签收；手工录入→编辑／完成／删除；事项进展与催办草稿；飞书卡片完成／稍后提醒；日报预览；模型与三个角色偏好；来源错误恢复；工作目录、Skills和MCP示例状态。`⌘K`／`Ctrl+K`打开录入，`Esc`关闭弹层。

已有Playwright工具环境及Chrome时，可运行以下独立设计检查。它不是生产依赖，也没有为此初始化包管理工程：

```sh
PLAYWRIGHT_MODULE=/absolute/path/to/playwright node design/verify.cjs
```

验证结果和截图在 [review](review/)；测试脚本会重写演示验证截图，不接触业务数据。`PROTOTYPE_ORIGIN`可覆盖本地服务地址，`CHROME_EXECUTABLE`可指定浏览器。
