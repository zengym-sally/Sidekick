## 本步行为与边界

普通值原样准备，宿主环境引用只按明确变量名查找，不继承整份环境，不读Shell／全局配置／`.env`，不自动传模型Key。准备结果绑定当前修订，只在宿主内部持有，不可序列化为IPC结果；本步不启动服务。测试全部注入合成环境表，没有解析真实秘密。

生产入口固定使用 `UnavailableCredentials`，没有Keychain或其他持久后端实例。生产GUI不能新增／替换安全值；已有引用仅显示“暂不可访问”。内存替身证明接口、归属和恢复逻辑；它不证明真实凭据持久化。服务安全引用绑定应用、规范根、稳定服务ID与变量名；公开视图只返回空安全值及状态。跨根／服务／字段／模型引用和客户端任意引用被拒；同名字段保留旧引用，变量改名需新值。

新值只经独立 `save_mcp_secrets` 命令提交，按操作ID登记不含秘密的私有journal，先写新引用并读回，再发布配置。旧引用及失败新引用不删除。响应丢失后依服务持有的操作ID精确对账，不以相同空字段猜测成功；确认后只清除仍等于本次提交的输入，较新草稿保留。内存输入不写浏览器localStorage。

恢复只核对实际旧／目标配置并归档日志，不重放凭据写入、不用日志目标覆盖配置。第三种磁盘状态、坏JSON／版本／字段／引用、超限、链接及归档碰撞保留现场并阻断。根、mcp、backups持有目录句柄，核对路径身份与0700；敏感文件0600、独立普通文件、单硬链接，读取有界。ready根冷重开缺私有目录也阻断，不重建。归档存在或新建两种路径均在删除原journal前确认backups目录同步；失败保留原journal。此为所属路径防错，不宣称敌对本机并发下的沙箱。

预算沿用计划§16.9：新值4KiB／64项／累计256KiB；完整安全输入512KiB；journal及原字节归档512KiB，目标配置256KiB；解析环境每值4KiB／累计256KiB，完整公开配置响应2,000,000B。真实后端接线、004、诊断、工具发现、活动快照保护及原生验收留后续。
