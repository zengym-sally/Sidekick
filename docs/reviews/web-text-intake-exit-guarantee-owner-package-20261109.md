### 1-B 若改为登记域退出保证：放弃什么、须改什么

**放弃（三项，显式接受）**：
1. **放弃「树已完整灭绝」的死亡证明**：退出确认改为**有类型证据的收敛判定**（worker 退出 ∧ attempt 组 ESRCH ∧ 注册集逐成员 proof-matched 灭绝 ∧ argv 扫描无命中——仅补充信号），命名如 `registry_extinct`。E1 类观察间隔逃逸从「停车」变为**残余**——幸存进程以用户权限运行、存活时间无界（直到被外部终止或自行退出），按 stray 台账逐次清扫记录与吊销责任披露；任何措辞不得把「已清扫」说成「已证明」，也不得声称残余有界（域内无隔离证明支撑）。
2. **未知副作用防线的依据改变**：从「死亡证明」改为「台账＋归因纪律」——attempt 工作区命名空间永不复用、产物引用携带 attemptId。**这只是归因与清扫对象纪律，不是 OS 权限隔离**：普通工作目录命名空间没有权限边界，幸存者以用户权限运行、可写用户可写的一切，不得声称「幸存者最多污染已退役目录」一类污染边界；残余生命周期无界，暴露面按 stray 台账与吊销责任披露。stray 台账是**审计面**，不是完整性声明。「未知副作用不盲重试」语义保留，证据基础变化。
3. **MCP env 秘密残余的存量披露必须显式认领**：逃逸 service 后代永久持有继承 env 值，域内机制收不回。配置引用化（(i) MCP server 配置不携带 secret env 值）只阻止**未来**继承，收不回已继承值——引用化是否真能减少未来继承还取决于最终 env 值，不能凭配置形式声称已解决；故 (i) 不能替代 (ii)。对**存量**已继承值，显式接受残余并披露用户侧吊销责任（(ii)）必须同时成立。**政策选向（引用化还是显式接受）属 W2 MCP 域**，与本包「W2 另域」的界定一致，不作为本 W1 差异包的必答条件捆绑；本包内保留的只是验收措辞——残余按 stray 台账逐次披露（§2.3）。

**须改的公开语义（冻结契约触点，行号见 §2）**：`attemptExitState` 的 `exited_confirmed` 谓词重定义（:54）；状态机「所属进程树退出已确认／退出无法确认」措辞（:75/:76/:80/:83-85）；槽位核算（:95/:226）；`exited_unknown` 回收与 resolve 门（:111/:112/:137/:198/:331/:128）；维护 hold 步骤（:294）；场景 19/24/28/29/30/31 措辞。**§4.6 安全路由（sideEffectSafety／needs_review）不在本包范围，不动。**

**须改的验收**：W1 旅程验收措辞（取消／退出核实步骤按登记域谓词放行＋台账披露残余，§2.3）；II 套件判据（T-6 类 SIGKILL 面期望值按登记域语义显式重写）——**前提注记**：「现套件判据严于冻结契约」是作者单方取证结论，**未获协调采纳**（`01a1beec` 明确不接收 confirmed 契约相符为准出结论、T-6 的 unknown 判据不改），仅作为 B 获批后条件性改写提案的标注前提，不作为既定事实写。

### 2.1 退出确认谓词（核心定义草案）

> **退出确认（登记域）**：attempt 的 worker 进程已退出，且其进程组不存在（kill(-pgid,0)→ESRCH），且该 attempt 注册进程集逐成员按帧来源＋存活期完成身份匹配的死亡确认，且 argv 扫描无命中（仅补充信号）。此条件记为 `registry_extinct`，是**有类型证据的收敛判定，不构成整棵进程树已灭绝的证明**——两次观察之间经 setsid／setpgid／双 fork 派生的后代仍可能存活（残余进程以用户权限运行、存活时间无界，按 stray 台账与吊销责任披露）。
