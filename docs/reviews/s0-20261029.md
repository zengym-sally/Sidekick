## 3. 关键失败已定位，后续构建须保留这些前提

- **Pi首次离线构建失败：** Git源码不含生成的模型目录数据。按上游`hydrate:model-data`补齐后，`build:offline`通过。准备脚本需要公开网络数据，固定源码和锁文件不等于完全离线或逐字节可复现；未修改生成的TS源码。
- **Rust版本解析：** 部分Tauri传递依赖已要求Rust1.90。项目采用兼容版本和Cargo解析fallback，实际锁文件在1.89编译通过，没有升级全局Rust。
- **macOS宿主过程宏：** 设置低版本`MACOSX_DEPLOYMENT_TARGET`时，本机编译出的宏动态库发生`mis-aligned LINKEDIT string pool`；最小对照中原始配置失败，移除该变量及wrapper两组成功。仅对在本机构建时执行的proc-macro移除该变量，目标应用部署配置保留。后续应在稳定macOS构建机重验。相关同类项目的[原始构建记录](https://github.com/msitarzewski/agency-agents-app/blob/main/docs/BUILD.md#troubleshooting-proc-macro-cant-find-crate-on-a-beta-macos)仅作为线索，结论依据本机对照。
- **模型打包入口：** 采用Pi lazy API入口时，esbuild单包的模型工厂初始化失败；改用官方直接API入口后，随包Node的真实调用通过，没有修改Pi源码。该结论只覆盖当前采用的入口组合，不概括全部Pi API。
- **CLI退出链路：** 经npm的Node包装器启动监听后，终止包装器曾留下本轮原生消费者；已核对命令及15分钟测试参数，只清理该子进程。探针改为直接启动随包原生CLI，并实测ready→SIGTERM→exit0；未停止共享总线。
- **npm锁文件：** 本机安全策略拒绝lock-only时解析的可选WASI远程制品；没有放宽安全设置。依赖版本与已有生成锁一致，在空目录中用同一manifest＋lock运行`npm ci --ignore-scripts`成功，安装106包。后续再改依赖须重新检查锁解析；当前arm64安装结果不代表其他平台。

## 5. 数据、资源与复现边界保持清楚

源码、runner及fixture均位于非忽略路径；构建、临时库、Tauri自动生成的ACL schema及安装包被忽略。ACL schema由构建重新产生，不是被遗漏的输入。当前应用改动按授权保持未提交，后续提交须包含这些新文件，不能说当前Git HEAD已包含完整S0工程。`vendor/pi/`保留原始上游`AGENTS.md`，没有新增项目根指令文件或修改上游指令。

安装包包含Node、lark原生二进制、合并JS、字体及许可文件；运行时JS的实际依赖清单和许可证副本随包保存。没有选用Vue Bits组件，也没有引入gsap／three；不能据此推导以后任意组件都轻量。未做完整供应链漏洞审计或CLI所有Go传递依赖的许可复核，推广前仍需检查。

当前仅验证本机macOS27.0.1；包中最低版本元数据12.0不是对12–26的兼容性证明。未经公证、没有第二台安装或升级证据。资源数字是当前合成诊断包快照，进程树尚未完整归属，不能当作长期常驻成本达标。
