v1／v2／v3到v4由同一个迁移事务执行。重建agent_runs时显式复制rowid及原列，保留历史及latest顺序；重建已知索引，其它业务表／已知索引保持。源版本所有待重建表均先核对历史表／索引定义；未知列、索引、触发器、依赖视图及额外入向外键均在备份／DDL前拒绝，包含v1的todo_events与CASCADE／SET NULL／NO ACTION扩展，避免“成功迁移”静默改写子记录。

v4仅允许role_trial＋三个非空既有角色，或mcp_probe＋NULL角色。角色试跑DTO保持原结果数组；旧读取／latest／bind／complete／error／cancel／interrupt入口限定role_trial。独立McpProbe DTO只持有稳定服务ID、配置修订、连接超时、有限工具名／schema SHA-256及有限错误码；不存命令、环境值、认证引用或模型快照。探测结果不是候选；不写正式sources／candidates／todos／todo_events。成功、失败、取消仅更新running探测，终态拒迟到；冷开未完成探测为interrupted，已完成结果保持；latest按明确服务ID过滤。

tool_calls本步只落结构与约束：归属业务run／角色run二选一，唯一调用ID，配置／schema及规范参数摘要、发送状态、响应类别／有限摘要与时间。没有原始参数、认证或原始工具输出列；外键及INSERT／UPDATE归属检查拒绝mcp_probe，角色用途／身份不可改写。没有工具发送／ACK／确认API或自动unknown恢复；这些仍属P3／P4，不能把建表当实际调用接线。
