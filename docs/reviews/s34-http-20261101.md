## 实现范围与历史验证

HTTP作为独立transport分支，只保存URL和整值宿主变量引用；表单／JSON同规范，保留旧stdio序列化、journal与历史快照。薄适配复用固定Pi，实现每POST/RPC的一次许可、冻结endpoint、禁重定向／鉴权重发／自动GET恢复，执行读取预算和绝对期限。

Rust从私有准备载荷固定HTTP run／server／revision／nonce／endpoint，与stdio guardian／keeper分支分开，不假造PID。调用复用possibly_sent→responded／unknown台账；缺有效响应、HTTP错误状态、取消／超时不能伪装为有效isError。unknown阻断同批、模型重试和迟到发布，冷开不重放。list_changed终止冻结任务；有限remoteClose仅扩展snapshot JSON，不改表结构或撤销未知业务。
