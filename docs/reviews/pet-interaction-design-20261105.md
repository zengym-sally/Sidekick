## 2. 前期技术比较

在体验选择前，两个全新上下文的只读评审者分别比较了动画/事件路线、原生窗口/命中/托盘路线；该比较不是正式设计准出。结论作为新设计的证据输入：

- 动画面：分层 SVG＋CSS 可以覆盖当前角色需求；外链 img 不能直接控制图内眼睛/手臂；程序控制器不能依赖 CSS 减少动效或窗口隐藏自动停止。通用业务 changed 事件不能判断真实新提交；幂等重放、零候选、撤销及试跑须隔离。
- 原生面：固定 Tauri 已有位置、工作区、穿透及 template 能力；不能把 start_dragging 返回/Moved 静默当松手。半隐优先屏内裁切，但命中恢复、菜单取消、混合缩放和屏间接缝仍需 P0。前端不必默认扩大 capability。
- 作者据此选择规范 T1–T5；owner 后续 D2 选择全部走右键菜单，原“hover 快捷栏＋原生菜单”技术建议已不采用。性能优劣和“低风险”不作为已测结论。
