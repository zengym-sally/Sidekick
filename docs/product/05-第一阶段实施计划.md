## 5. 首个 AI 闭环按用户实际操作验收

1. 从 Finder 打开安装包，选择默认或自定义工作目录；无模型时可以直接手工记事。
2. 配置真实模型，凭据存系统钥匙串，点击最小调用测试得到真实成功或失败反馈。
3. 粘贴一段含本人执行、本人跟进和未定期事项的非敏感文本，其中一项明确“今天跟进、周五交付”；显示整理进度，可取消。
4. 候选卡展示原文、事项类型、负责人、时间和推断依据；本轮新导入在签收前不增加正式事项。
5. 编辑一条、丢弃一条，用自然语言修改一条并预览；另将一条候选选择关联已有事项，签收后只增加来源关联、不额外新建事项，不静默覆盖其关键字段；重复点击只生效一次。
6. 主窗今日与全部事项能查到签收结果；“无截止”留在未定期分组。跟进时间与交付截止分别显示，今日归组核对“今天跟进、周五交付”。完成一条后列表与详情一致；跨窗口一致性在S4/S5另验。
7. 退出重开，事项、未处理候选、拒绝结果与历史仍在；同一任务重试不重建已签收事项。

### 12.2 模型配置和凭据不进入前端回读或日志

`config/providers.json`保持providers数组，`config/models.json`保持models数组，保留样例字段和未知非秘密元数据；Sidekick在models根扩展版本／修订和defaultModelId。导入成对校验唯一ID、引用、启用状态、默认绑定、端点及auth二选一，不静默覆盖apiKeyEnv/apiKeyRef。禁止URL用户信息和明文密钥字段，extraHeaders仅非秘密固定头；不把模型声明直接透传为供应商参数。

两文件以当前根的串行配置事务与私有journal提交：先验证完整新配置，再原子写journal，依次原子替换两文件，最后清journal；恢复时在向读者发布前完成同一已验证journal。拒绝链接、未知版本或损坏配置；故障注入核对任一写入点失败／重开后只能得到一套完整配置，不能混用。保存出现提交后错误则读回对账，不能一律声称未保存；若恢复／读回仍失败，返回配置保存结果未知，保留journal、新旧凭据引用和用户输入，禁止后续配置保存或启动模型任务，先恢复并对账。未知结果不得删除新凭据。任务读取的是已发布快照。

### 12.4 日期不让模型猜时点，交付与跟进分别解析

模型只给原文日期表达，不直接生成UTC时间戳。Runtime的确定性日期转换按宿主提供的来源锚点与IANA时区运行；支持今天／明天／后天、周／本周／下周、常见公历日期和明确时分。“下周五”按周一为一周起点解释为下一自然周周五；原文时间优先于导入时间。测试冻结锚点覆盖跨周、跨年与时区。

只有日期的表达保留day精度，不补造17点或23:59；UTC值仅为该日定位坐标，不对外显示为精确截止。既有TimePoint增加可省略precision（默认minute，兼容旧JSON及操作规范请求）；day按其原时区显示日期、按该日结束判断逾期。表单／候选支持仅日期和明确时刻，编辑未改时间不重算；交付与下次跟进独立，今日跟进优先按下次跟进归组。

DST缺失／重复或无法理解的表达不猜结果，保留原文与警告；签收前用户补充时间，或显式核对后接受未定期。缺源时间的回退锚点在提交与卡片可见，不隐藏假设。自然语言修改的相对日期另用指令时间快照。

### 12.5 Runtime生命周期与安全边界

Vue → Rust窄命令 → 持久来源／run → 随包Node／Pi → schema校验结果 → 候选 → 人工签收 → SQLite。模型文本和输出均不构成正式写入授权。Rust只在对应run仍running、来源匹配、未取消时收结果；不提供前端“直接完成run／写候选结果”通用命令。

密钥通过子进程stdin传入Provider认证解析器，不进入argv、文件、模型上下文或事件；stdout为有界NDJSON协议，stderr不透传原始服务响应。配置与产物不存密钥；UI只显示真实错误类别与恢复入口。应用不打印原文／候选／字段／请求快照；测试证据只用合成或脱敏材料。

同一时刻只运行一个整理／修改／连接测试，创建任务不长时间持有数据库锁。状态／取消使用独立控制锁；先持久cancelled再通知agent.abort，超时终止本应用创建的进程组。产品强制整个run总期限120秒，包含模型重试、工具循环与等待；每条Bash缺省30秒、最大60秒，实际再受run剩余期限限制，模型省略或请求过大也不能无限等待。期限到达走统一取消／清理。

Pi默认Bash在macOS会detached建组，不能仅杀Runtime组。本轮不改vendor源码，通过Pi公开BashOperations扩展将执行托管给随包Node工具守护子进程：守护进程独立建组，Bash及其普通后代留在守护组内；守护进程仅持有Runtime专用stdin存活通道，EOF／终止信号／期限到达即停止并清理整组。Runtime监听宿主stdin EOF，立即abort网络／工具并关闭工具存活通道；宿主登记Runtime及守护组的run nonce／PID，结果与退出时回收并等待，不能只登记一个Runtime PID。杀宿主由EOF触发Runtime／工具清理，杀Runtime由守护EOF清理；受控脚本存活PID逐项核对。主动自行detach／脱离托管的任意脚本不在强回收保证内，已发生的外部副作用不撤销。

主进程正常退出回收所属子进程；冷启动将遗留queued／running标interrupted，可由用户重试，不伪装完成。取消、迟到结果和重试都不直接写正式事项。

网络请求超时与整个run期限共同生效。临时网络／429／5xx仅按配置最多2次退避，重试当前模型请求上下文，不从头重放已经执行的工具；已有部分结果流或副作用状态未知时停止而非重放工具。401、缺凭据、配置错误和非法结果停止，不盲目重发。S2真实测试走已选DeepSeek和合成业务材料；无需飞书、无对外消息，不提前跑提醒、日报或桌宠。Read/Bash继续遵守已批准当前用户通用能力；正常业务确认校验不构成文件沙箱，不承诺任意脚本无法直接改库或外发。

### 13.3 配置、快照和试跑的最小契约

- 设置从左下角个人入口进入，仍默认个人信息；保留个人信息／通用设置／模型／关于，增加“智能体”“工具”。智能体页固定3张角色卡＋当前角色详情；工具页分Skills与MCP，不增加侧栏一级菜单。沿用入口浅琥珀、保存实心琥珀及导航墨蓝激活，维持窄窗、键盘和焦点行为。
- `config/agents/<roleId>.json`只保存版本／修订、可空`modelId`（空即继承）、已定义的偏好及补充说明；角色基础职责与输出契约随应用固定，不提供第四个角色、任意系统提示词替换或工具审批开关。缺文件使用默认；损坏／未知版本／链接拒绝覆盖，显示可恢复错误。每角色单文件私有原子保存，预期修订校验防旧编辑覆盖；保存结果未知保留草稿、读回对账后才继续。恢复默认显式作用于当前角色，不删除模型或Skills。
- 模型保存须同时检查角色覆盖引用：被引用模型的移除／禁用不能静默回落到默认；提示先解除覆盖或修正配置。角色覆盖仍使用S2已支持的OpenAI兼容调用，不顺带扩展供应商协议。模型配置禁用toolCall时，普通文本仍可用，工具试跑明确不可用，不能报工具已验证。
- 新任务固定角色版本、解析后的模型与供应商修订、个人信息、偏好、技能索引／内容标识、MCP配置与实际发现的工具schema、输入锚点。配置保存、重扫、模型默认变化只影响新任务；当前任务已使用的技能正文／支持文件不能在运行中静默换版，执行前按任务快照固定有效技能包。凭据只按引用运行时注入，不存入快照、argv、前端回读或日志。
- 保留S2 `runs`／候选表语义，不将advisor或工具探测伪装成extract/test。追加003迁移建立独立`agent_runs`，保存可空角色（仅工具探测为空）、用途（角色试跑／今日建议／MCP探测）、状态、非秘密快照、输入／结果、错误与时间；试跑通过宿主结果路由无正式业务写入接口。另增最小`tool_calls`台账，按业务run／agent run归属保存调用ID、服务／工具名、规范参数的摘要、发送边界状态与时间，不存秘密或原始认证信息，覆盖下文未知结果恢复。复用单活动执行控制、120秒总期限、取消／迟到结果终态和冷启动interrupted，不常驻三个智能体、不建设队列平台。
- 今日建议结果带事实快照标识、日期／时区、被引用事项ID与版本；只读展示，事实变化后标旧／刷新，迟到结果不冒充当前建议。宿主计算计数和清单，模型只给排序与说明；失败不清空本地事实，重开可展示标明生成时间及是否过期的最近成功结果。
- 升级前对v1／v2根做一致性备份，003仅追加新表，不修改001／002或S2事项历史；失败整事务回滚，旧包拒绝v3。先在临时根验证v2→v3与v1直升，再接普通包；不触碰真实用户根。回退代码前须保留现根并使用兼容包／备份，不能直接让S2包写v3。

### 13.4 Skills与MCP按实际任务拥有生命周期

**Skills。** 本机仍有28个`lark-*`技能包；本轮只读核对了8个相关包的文件与直接引用，未复制或执行。正式内置集从会议／妙记、消息、文档及共享规则开始，根据真实相对文件引用和跨包跳转补齐依赖，不按名称正则把命令场景误算成独立Skill，也不因依赖扩大业务范围。实施时记录固定来源提交、完整文件清单、哈希、CLI兼容版本与许可证；不从用户本机路径动态打包，不在启动时拉latest。上游[官方Skills目录](https://github.com/larksuite/cli/tree/main/skills)与[MIT许可证](https://github.com/larksuite/cli/blob/main/LICENSE)已只读核对；本机包与固定上游版本的逐文件对应、完整依赖及独立可分发资源清单仍待S3.2验证，未验证不能算技能分发完成。

用户技能目录和内置升级区分：首次只安装缺失包；同名用户包报告冲突，明确恢复覆盖范围并先备份，不静默合并。显式扫描只含工作根skills（`includeDefaults:false`）；有效技能包连同正文、references／scenes／scripts进入任务快照，读文件／执行脚本以快照位置解释相对路径，产物cwd仍为`runs/<runId>/`。新扫描发布一份完整索引，重扫失败不把半份索引当成功；坏包／重名包显示不可用，不随机取先到版本。技能包越界链接、断引用和体积超限需明确诊断，这只是包完整性规则，不宣称限制通用Bash。

**MCP。** `mcp/servers.json`为私有版本化配置，固定服务ID、传输、启用状态、command／args／cwd或URL、超时、非秘密env／headers及秘密引用。复用S2钥匙串命名空间、先验证后写新引用、原子发布与结果未知读回规则；模型Key不自动传给服务。缺环境变量、缺运行依赖、认证方式不支持时显示真实状态，不自动安装依赖、不把OAuth缺失当已登录。本切片实现无认证及显式env／钥匙串引用的静态认证；不承诺通用OAuth向导。

认证只经显式env／header引用注入，不把秘密放入command／args；拒绝服务URL用户信息及已知认证查询字段的明文凭据。HTTP经应用侧注入的fetch统一设置拒绝自动重定向，覆盖POST、GET、会话关闭DELETE，不依赖默认fetch只剥离标准认证头的行为；重定向显示目标配置错误，需修正服务地址后重连。合成自定义认证头也纳入脱敏和跨目标泄漏反例，不只测试Authorization。

采用与现有Runtime一致的**任务内连接**：设置“连接／刷新工具”为有界诊断会话，结束即关闭，界面显示“最近测试成功＋时间／上次发现工具”，不伪装长期已连接；业务任务按启动时配置重新握手、发现并注册。只有活动会话显示“当前连接中／已连接”；“断开”终止该会话，若业务任务正在使用则明确取消对应任务后关闭。修改／禁用配置不悄悄改变正在执行的快照，显式断开是独立控制动作。无常驻工具服务管理平台。

MCP工具名使用稳定服务ID＋原工具名的受限编码和哈希，校验64字符限制及碰撞；参数依工具schema校验，schema／数量／输出超限明确失败，保留`isError`语义，不把工具错误当成功文本。默认不调用任意“第一个工具”来测试连接；真实tool call只在用户发起的任务中执行。连接缺省10秒、单工具30秒，均不得超出120秒run剩余期限；HTTP重连不能自动重放已发出的未知结果调用。

该不重放保证同时落在**传输层与AgentTool执行层**：区分未发出、已确认响应（含明确工具错误）、已发出但结果未知。宿主先持久登记“可能已发出”边界，再允许Runtime提交调用；进程在边界之后中断而无持久确认响应，一律保守转unknown。MCP取消通知不证明服务端未执行；未知结果不能仅返回普通`isError`让模型接着尝试，而是登记安全调用ID／摘要、置停当前run、abort Agent并关闭连接，拒绝该run后续工具调用，不自动重跑任务。界面明确“操作可能已生效，请先核对外部结果”；重开保留该提示，不能只泛化为普通interrupted或默认重试。只有未发出或有明确响应的错误才按对应类别处理；用户核对后显式发起的新任务不等于系统重放旧请求。该规则适用于stdio和HTTP，既不撤销已发生副作用，也不增加逐工具审批。

stdio首先用受控脚本验证生命周期，再接UI：Pi公开`McpTransport`接口允许应用侧适配，用S2守护／存活通道模式将server和普通后代纳入可回收组、登记到宿主；不能仅登记Runtime或依赖SDK正常close。复用Pi协议客户端、结果转换与HTTP transport，不改vendor、不自造MCP协议栈。此生命周期适配可行性是S3.3前置检查；若固定接口无法满足，停在探针并重新技术裁决，不接受孤儿进程后继续。HTTP会话取消须关闭stream和重连等待；双方都记录安全错误类别，屏蔽原始敏感stderr和认证头。

验证按阶梯进行：每步先失败反例及聚焦检查，再固定Pi打包集成与受控进程／HTTP；实现稳定并独立交付复核后，才集中跑现有`npm run check`与普通包构建。S3新增测试／样本／来源清单放入可检出的`tests/`／资源目录，按需接入package scripts，不能依赖忽略的本机文件。真实模型继续只用owner已指定配置及合成资料；本轮计划阶段不调用。S3不发送飞书消息、不读取新增个人资料、不擅自使用未知远端MCP。需要真实业务服务时再取得对应接入信息及具体操作授权，不把受控服务算作真实业务接入。
