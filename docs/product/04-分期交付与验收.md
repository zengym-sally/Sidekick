| 工作目录 | 本机默认根与主机预设允许目标的切换可用，后端校验能力/目标/版本，未知结果按操作 ID 查询；已有根执行历史无法证明连续时暂停调度并进入恢复核对，A→B 发生外部操作→切回 A 不重发；Linux 代理使用固定根并拒绝浏览器切换；配置／数据库／产物／技能／MCP位置正确；停任务迁移、WAL一致性、失败回原根、旧数据保留；不误读开发者全局配置 | F17 |
| 源码与 Bash／Skills | 干净检出取得Pi源码，从同一提交构建内部包；无系统Node仍可执行配套CLI；完整技能相对引用可读，添加／修改／冲突／重扫有结果；Bash cwd、环境、流、超时、取消与进程清理逐项留证 | F17 |
| MCP | 受控stdio与Streamable HTTP服务实际完成发现和调用；验证配置失效、依赖缺失、认证失败、同名工具、超时、取消、重连和退出清理；工具可供固定角色使用，无新增角色或逐工具审批 | F17 |

飞书发送受理、飞书端可见、本人已读分别记录；不能把API成功等同已读。休眠、断网、拒绝系统通知、桌宠隐藏分别验证补偿，不以正常条件成功推导长期100%触达。关键业务不变量必须在全部相关样例中成立。

Bash 验收明确采用当前用户的通用执行能力，工作目录不是沙箱；正常业务接口的签收测试不包含“任意脚本无法直接改库”的保证。额外MCP服务或本机脚本的依赖不自动成为随包承诺，缺失时须明确显示失败。

## 3. 精美程度与常驻成本一起检查

产品按既定品牌制作，W5 验收真实 Web 的文本可读性、键盘、焦点、队列状态与提示文案，D1 再验安装版桌宠四态。卡片和输入区保持扫描性；装饰动画不阻碍操作，工作模式保留静态提醒与未读。

Vue／motion-v／@vueuse/core／TDesign 沿用当前锁定版本，新依赖按授权验证类型、构建与事件行为。Vue Bits 按组件检查依赖；桌宠优先 SVG，重型背景只在确有价值时引入。记录同机同数据下空闲CPU、进程树RSS、安装包体积与隐藏窗口的动画行为；尚无基线，不照搬旧稿未实测的资源预算。

安装说明必须写明支持的macOS、arm64、签名／公证状态和飞书接入前提；第二台安装与升级路径先验证，不以开发机启动代替。复制备份前保证SQLite快照一致，迁移失败不覆盖原数据。

## 4. 业务效果从少量真实样本开始采集

| 指标 | 最小采集方法 | 输出 |
|---|---|---|
| 录入／签收耗时 | 固定若干等难度材料，手工与跟班交替计时；从开始阅读到全部目标事项保存，包含纠错与签收 | 每条／每批耗时、任务数、失败数；不混同模型返回时间 |
| 提取质量 | 先人工标注本人执行／跟进、行动、时间与原文证据；另留不参与调优的样本 | 精确率、召回率、日期错误和误关联的原始计数 |
| 漏项与拖期 | 连续记录手工和试用两个观察期，每天从原文复核唯一到期事项；区分未知悉漏项与已知但延期 | 原始分子／分母及样本范围；基线为0或样本不足不报相对改善 |
| 跟进与日报价值 | 记录新增进展中多少确有帮助、多少需纠正；核对日报事实与用户修改 | 有用／误关联／纠正数量，代表性案例和本人反馈 |
| 提醒表现 | 正常与异常场景分别记录通道结果和补偿时延 | 可见、失败、未知各多少，不只展示成功样例 |

可使用本地表格记录 `sample_id, phase, source_ref, item_id, started_at, saved_at, due_at, outcome, error, evidence_ref`；进展补记录关联是否正确，提醒补记录各通道时点。当前没有已采集基线，不沿用“节省多少秒”“下降50%”等旧估计作为已达成结果。
